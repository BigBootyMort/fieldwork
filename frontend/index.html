🌑 Dark web search — Ahmia.fi

Ahmia indexes public .onion sites. No Tor required — results reference .onion URLs but the index itself is clearnet. Results are stored as DarkWebMention nodes.

Only use for legitimate investigative purposes. Treat results as leads requiring verification.

🌐 Federated OSINT Search

Fires your query against all connected OSINT sources simultaneously. Sources without API keys are skipped automatically.

Sources: Internal graph · Shodan · VirusTotal · HIBP · GitHub · News · Aleph · Dark Web · Censys · Dehashed
🛰 Censys Internet Scan

Search internet-wide scan data — open ports, banners, certificates. Requires CENSYS_API_ID + CENSYS_API_SECRET in .env (free: 250 queries/month).

🔑 Dehashed Breach Search

Search 15 billion+ leaked credential records by email, username, IP, or name. Requires DEHASHED_EMAIL + DEHASHED_KEY in .env.

📧 Email Header Analyzer

Paste raw email headers (everything above the body) to trace the delivery path, detect spoofing, check SPF/DKIM/DMARC, and extract IPs into the graph.

📱 Phone Number Intelligence

Parse, validate, and enrich any phone number. Identifies country, carrier, line type (mobile/VoIP/landline), and generates investigation resource links. Adds a Phone node to the graph.

📥 Bulk entity import

Upload a CSV, JSON, or TXT file to batch-add entities. Entities are added as case subjects automatically. Same file uploaded twice is a no-op (content-addressed merge).

Supported formats & examples
CSV — columns: type,value[,note] or value (type auto-detected) 
type,value,note
Email,jane@corp.com,primary contact
Domain,corp.com
IP,192.168.1.1
Phone,+44 7700 123456
JSON — array of {"type","value","note"} 
[{"type":"Email","value":"jane@corp.com"},
 {"type":"Domain","value":"corp.com"}]
TXT — one value per line (type auto-detected) 
jane@corp.com
192.168.1.1
https://corp.com/login
